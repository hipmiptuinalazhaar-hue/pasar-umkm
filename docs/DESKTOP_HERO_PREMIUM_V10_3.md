# Desktop Hero Premium V10.3

Tanggal: 2026-09-23

P1-P4 hero desktop dibangun ulang agar terasa seperti produk marketplace premium, bukan banner promosi.

## P1 — Removal
Panel logo besar V10.2 dihapus total.

## P2 — Marketplace mockup
Panel kanan kini berupa mockup UI Pasar UMKM dengan:
- topbar brand + search
- kategori generik
- panel ekosistem
- status platform
- discovery actions
- floating UI cards

Tidak ada seller nyata, nama toko, nama produk, atau harga palsu.

## P3 — Brand hierarchy
Logo resmi Pasar UMKM tetap dipakai, tetapi hanya sebagai identitas kecil di topbar mockup.

## P4 — Unified composition
Hero kiri mendapat trust chips dan kolom kanan dibesarkan untuk mockup. Visual memakai layer transparan, depth, glass, gold accent yang terkendali, dan hover perspektif ringan pada pointer desktop.

Mobile tidak diubah.
